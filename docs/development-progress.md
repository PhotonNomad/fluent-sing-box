# 开发与验证进度

更新：2026-10-01。本文记录实际实现与验证，不能代替全部 52 项功能验收。

## 客户端变化

- 添加和编辑共用按协议显示字段的表单，支持 11 种常用协议；类型、TLS、传输方式等使用选择控件，保留高级 JSON 编辑入口。
- 服务器父条目保留名称、地址、协议和展开箭头；默认服务器、连接测试、编辑、复制、删除放入展开后的子条目，采用 PowerToys 设置页布局。
- 导入增加逐行预览和选择，允许只导入有效项；错误提示避免回显链接中的凭据。完整配置可区分 outbounds 与 endpoints。
- 本地监听支持 HTTP 与 SOCKS；增加地址规则校验、系统代理与应用代理规则范围，以及按应用服务器设置 DNS 出口。
- 核心启动前检查候选配置；配置错误保留现有核心，重启失败尝试恢复之前运行的配置。主窗口存活时可检测核心异常退出并处理代理恢复。
- 配置存储增加临时文件、备份和损坏恢复；日志页提供真实日志、过滤、暂停、清空显示与脱敏导出。
- 连接测试通过独立核心和显式本地代理访问 Google HTTPS，不切换 Windows 系统代理。真实远端节点尚未验证。
