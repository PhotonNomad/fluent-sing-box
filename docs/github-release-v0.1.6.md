# fluent sing-box v0.1.6（Windows x64 测试版）

## 安装

- 推荐 `FluentSingBoxUserSetup-0.1.6-x64.exe`：当前用户安装，包含 MSI。
- `FluentSingBoxUserSetup-0.1.6-x64.msi`：当前用户的独立 MSI。
- `FluentSingBoxSetup-0.1.6-x64.exe` / `.msi`：全机安装，需要管理员权限。
- 安装包自包含 .NET 和 Windows App SDK，无需另装这两个运行时。系统要求 Windows 10 19041 或以上，x64。
- 当前用户与全机安装不能共存；同范围升级保留配置并复用原安装位置。校验文件见 `SHA256SUMS.txt`。

## 更新内容

- 新增 MSI / EXE 安装包、安装目录选择和独立更新器。
- “版本和更新”改为折叠卡片，提供自动下载安装和新更新通知两个选项。
- 修复编辑程序组时多行程序名或路径只显示第一行、再次保存可能丢失其余条目的问题。
- 完善退出清理、托盘生命周期和配置保存处理。

## 测试版限制

- 安装包尚无 Authenticode 代码签名，Windows 可能提示未知发布者。
- 本次 GitHub 发行不包含本机测试更新目录、测试公钥或私钥。
- 当前 GitHub 自动更新要求受信任的发布者签名；此测试版请从 Release 手动下载安装，不将未签名安装器作为自动更新执行。
- 开发机验证了用户范围安装和升级；全机范围及干净 Windows 客体安装仍需补充验收。

仓库可见性保持不变；私有仓库中的 Release 仅向有仓库访问权限的用户开放。
